# REM Sleep Data Analysis & Predictive Modeling

A comprehensive statistical analysis project in R aiming to identify and model the physiological and lifestyle factors that significantly affect Rapid Eye Movement (REM) sleep. 

## Project Overview
REM sleep is critical for memory consolidation, emotional regulation, and physical recovery. This project utilizes statistical inference, exploratory data analysis, and multiple linear regression to determine how daily habits (like alcohol and caffeine consumption) and physiological traits (like age, BMI, neck size, and Awakening Index) impact the percentage of REM sleep a person gets.

## The Data
The analysis is based on the `04_sleep.csv` dataset, which contains 106 patient observations across 9 variables:
*   **Demographics & Physiology:** `age`, `gender`, `BMI`, `necksize`, `sbp` (Systolic Blood Pressure).
*   **Lifestyle Habits:** `alcohol` and `caffeine` consumption.
*   **Sleep Metrics:** `REM` (Percentage of REM sleep) and `AI` (Awakening Index).

## Methodology
The project follows a rigorous statistical workflow using R:
1.  **Exploratory Data Analysis (EDA):** Descriptive statistics and normality testing (Shapiro-Wilk, Kolmogorov-Smirnov/Lilliefors).
2.  **Bivariate Analysis:** Examining relationships using Spearman/Pearson correlations and independent T-tests for categorical variables.
3.  **Regression Modeling:** Building a Multiple Linear Regression model and utilizing Stepwise Selection (evaluating both AIC and BIC criteria) to find the optimal balance between model simplicity and explanatory power.
4.  **Model Diagnostics:** Conducting thorough assumption checks on the final model, including normality of residuals (Q-Q plots), homoscedasticity (Levene's test, Non-constant Variance test), independence (Durbin-Watson, PACF plots), and linearity (Cook's Distance for outlier detection and removal).

## Prerequisites
To run the analysis script, you will need **R** and the following packages installed:
* `sjmisc`, `sjPlot`, `car`, `psych`, `tidyverse`, `likert`, `lme4`, `dplyr`, `nortest`, `cocor`, `olsrr`, `flexmix`

## Running the Code
1. Ensure the `04_sleep.csv` dataset is located in your working directory.
2. Open and run the `Κώδικας_Εργασίας_Ανάλυσης_Δεδομένων (3).R` script.
3. The script will output frequency tables, correlation matrices, residual diagnostic plots, and the final summary of the linear regression model.

## Key Findings
*   **Crucial Factors:** The final selected model highlights Age, Neck Size, Alcohol consumption, and the Awakening Index (AI) as the most relevant variables.
*   **Negative Impacts:** Both a higher Awakening Index and the consumption of alcohol were found to have a notable negative impact on the percentage of REM sleep. 
*   **Outlier Influence:** Medical data contains high variance. Removing just four extreme outliers (identified via Cook's Distance) significantly improved the model's Adjusted R-squared and linearity without compromising the sample size.
